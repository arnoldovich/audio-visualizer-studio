# Audio Visualizer Studio

**Audio Visualizer Studio** — безкоштовна Windows-програма для створення музичних відео та аудіореактивних візуалізацій.

Програма має багатошарові ефекти, попередній перегляд, таймлайн, підтримку зображень і субтитрів, а також експорт готового відео через FFmpeg.

## Основні можливості

- Створення аудіореактивних музичних візуалізацій.
- Багатошаровий стек візуальних ефектів.
- Попередній перегляд композиції.
- Waveform-таймлайн із навігацією по аудіозапису.
- Налаштування розміру, частоти кадрів і якості відео.
- Експорт у формат MP4 із кодеками H.264 та H.265.
- Підтримка програмного й апаратного кодування.
- Додавання фонових і центральних зображень.
- Робота із субтитрами.
- Готові набори параметрів для горизонтального та вертикального відео.
- Швидкий тестовий експорт короткого фрагмента.
- Українська й англійська локалізації.
- Світла, темна, синя та пісочна теми оформлення.
- Автоматичне збереження проєктів.
- Локальний кеш аналізу аудіо.
- Вбудовані FFmpeg і FFprobe.

## Системні вимоги

- Windows 10 або Windows 11.
- 64-бітна операційна система.
- Приблизно 650 МБ вільного місця для встановлення.
- Додаткове місце для аудіофайлів, проєктів і готових відео.
- Рекомендовано щонайменше 8 ГБ оперативної пам’яті.

Швидкість попереднього перегляду та експорту залежить від потужності процесора, відеокарти, вибраної роздільної здатності, частоти кадрів і кількості ефектів.

## Встановлення

1. Відкрийте сторінку [останнього релізу](https://github.com/arnoldovich/audio-visualizer-studio/releases/latest).
2. У розділі **Assets** завантажте інсталяційний файл `.exe`.
3. Запустіть завантажений файл.
4. Виберіть мову інсталятора.
5. Прочитайте та прийміть ліцензійну угоду.
6. Виконайте вказівки майстра встановлення.
7. Запустіть програму через меню «Пуск» або ярлик на робочому столі.

Програма встановлюється для поточного користувача й зазвичай не потребує прав адміністратора.

Python, FFmpeg та інші бібліотеки встановлювати окремо не потрібно — необхідні компоненти вже включені до дистрибутива.

3. Натисніть **Виконати**.

Завантажуйте програму лише з офіційної сторінки релізів цього репозиторію.

## Перевірка завантаженого файла

Для кожного релізу публікується контрольна сума SHA-256. Вона дозволяє перевірити, що інсталяційний файл не був пошкоджений або змінений.

Перевірити файл у PowerShell можна командою:

```powershell
Get-FileHash -Algorithm SHA256 ".\Audio_Visualizer_Studio_Setup_4.21.5.exe"
```

SHA-256 інсталятора версії 4.21.5:

```text
9C6F846A68359493036866448A03D65AC52F286732E188AD9EBABF44F8745198
```

## Видалення програми

Програму можна видалити стандартними засобами Windows:

1. Відкрийте **Параметри**.
2. Перейдіть до **Програми → Інстальовані програми**.
3. Знайдіть **Audio Visualizer Studio**.
4. Натисніть **Видалити**.

Також можна скористатися деінсталятором у папці встановленої програми.
